# 마찰전기 시뮬레이션

풍선과 털가죽을 문지를 때 전자가 이동해 물체가 대전되는 과정을 보여 주는 중학교 과학 시뮬레이션입니다.

## 실험 (상단 메뉴에서 선택)

### 실험 1 · 마찰 전기 현상 관찰하기
면장갑으로 두 고무풍선을 문지른 뒤 어떻게 움직이는지 관찰합니다. 단계는 자유롭게 오갈 수 있습니다.

1. **문지르기**: 면장갑을 드래그해 초록/빨간 풍선을 문지릅니다. 풍선은 (−), 장갑은 (+)로 대전됩니다.
2. **풍선 두 개**: 스탠드에 매달린 초록 풍선에 빨간 풍선을 가까이 하면 서로 밀어냅니다(척력).
3. **장갑 가까이**: 면장갑을 매달린 풍선에 가까이 하면 서로 끌어당깁니다(인력).

### 실험 2 · 풍선과 털가죽


- **왼쪽 (문지르기)**: 풍선을 드래그해서 털가죽 위에서 문지르면 마찰량이 올라갑니다.
- **오른쪽 (전자의 이동)**: 마찰량에 비례해 털가죽에서 풍선으로 전자(−)가 이동합니다.
  - ① 대전 과정: 마찰하기 전 / 마찰하는 중 / 마찰한 후
  - ② 털가죽에 끌림: 대전된 풍선과 털가죽 사이의 인력
  - ③ 머리카락에 끌림: 정전기 유도로 머리카락이 풍선에 붙는 현상
- **다시 하기**: 처음 상태로 되돌립니다.

인력의 세기는 풍선의 순전하량에 비례하고 거리에 반비례합니다(중학생 수준으로 단순화). 전하의 총량은 항상 보존됩니다.

## 실행

빌드 도구가 없는 정적 사이트입니다. `index.html`을 브라우저로 열거나 정적 서버로 실행합니다.

```bash
python -m http.server 5173
```
